# Extension icons and logo

- **`logo.svg`** — Same as the website favicon. Used in the popup header.

- **Toolbar icon (optional):** To show this icon in the Chrome toolbar, add `icon16.png`, `icon48.png`, `icon128.png` (16×16, 48×48, 128×128) and add the `default_icon` and `icons` entries back to `manifest.json`. Export PNGs from `logo.svg` if needed.
